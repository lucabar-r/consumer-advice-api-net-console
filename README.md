# Consumer Advice API

Uma aplicação de console desenvolvida em C# e .NET para consumir a API pública [Advice Slip](https://api.adviceslip.com/advice). O programa realiza requisições HTTP assíncronas e desserializa os dados em formato JSON para exibir conselhos aleatórios em inglês diretamente no terminal.

Projeto desenvolvido como atividade prática para a disciplina de Usabilidade, Dev. Web, Mobile e Jogos no UniBH, sob orientação do Professor Daniel Henrique Matos de Paiva.

## Tecnologias Utilizadas
* C# 
* .NET (Console Application)
* `HttpClient` para consumo de APIs RESTful
* `System.Text.Json` para serialização/desserialização de dados
